# v1.3 센서·장치 제어 설계 노트

v1.3.0 마일스톤에서 PC 장치를 다루는 기능들의 설계 메모다. 기능마다 절 하나씩.

## 모니터 DDC/CI (#144, 드라이버 #153)

주 모니터의 **밝기 · 입력 전환 · 전원**을 DDC/CI(MCCS VCP)로 바꾼다.

- **옵트인**: `config.json` `"monitor": {"enabled": false}`. 원격 허용(SmartThings · 텔레그램 · 앱)도 이 스위치 하나다. 감사 대상 키(`monitor.enabled`).
- **실행 위치**: `user-action monitor get|set`을 **콘솔 세션**(물리 모니터가 붙은 세션)에서 실행한다. RDP 세션의 디스플레이는 가상이라 DDC가 없다. 콘솔에 로그인한 사용자가 없으면 `409 no_user_session`.
- **바인딩**: `dxva2.dll`(`GetPhysicalMonitorsFromHMONITOR`, `GetVCPFeatureAndVCPFeatureReply`, `SetVCPFeature`, `GetCapabilitiesStringLength`, `CapabilitiesRequestAndCapabilitiesReply`)과 user32(`EnumDisplayMonitors`, `GetMonitorInfoW`, `QueryDisplayConfig` — 이름 "DELL U2720Q")를 직접 호출한다. COM 없음, 포인터 변환은 `Proc.Call` 인자 안에서만.
- **id**: 주 모니터가 `m1`, 나머지는 왼쪽→오른쪽, 위→아래 순 `m2`, `m3` …. 배치가 바뀌면 번호도 바뀌므로 명령은 늘 주 모니터에 간다(서비스가 저장된 목록에서 주 모니터 id를 골라 `--id`로 넘긴다).
- **VCP**: 밝기 `0x10`(현재/최대를 0–100으로), 입력 `0x60`(MCCS 이름 `vga1 vga2 dvi1 dvi2 composite1… component3 dp1 dp2 hdmi1 hdmi2`, 모르는 값은 `vcp:0xNN` — USB-C는 기종마다 달라 보통 이 꼴), 전원 `0xD6`(1 = `on`, 2–5 = `standby`, 그 밖 `unknown`). 끄기는 `0xD6 = 4`(DPM off).
- **입력 목록**: 능력 문자열 `vcp(… 60(0F 11 12) …)`에서 읽는다. 기종마다 띄어쓰기 · 대소문자 · 붙여 쓰기가 달라 hex 덩어리를 바이트로 쪼개 읽는다. 못 읽으면 현재 입력만.
- **캐시**: DDC 왕복은 값 하나에 수십~수백 ms, 능력 문자열은 1–2초라 status는 기다리지 않는다. 마지막 읽기를 내보내고, 60초에 한 번까지 백그라운드에서 다시 읽는다. 명령은 응답의 값(능력 문자열 없이 다시 읽은 것)을 바로 반영하고 3초 뒤 전체를 다시 읽는다. user-action 제한 시간은 모니터만 15초.
- **계약**: `status.monitors`(enabled일 때만 키가 있음, 읽기 전에는 `[]`), `features`에 `"monitor"`, `/st/v1/command`의 `monitor_brightness`(value 숫자 0–100) · `monitor_input`(value 문자열) · `monitor_power`(value `"on"|"off"`). 응답은 보통 명령 응답에 `monitor`(다시 읽은 주 모니터)를 더한 것. 실패: `403 monitor_disabled`, `409 no_user_session`, `400`(값), `501 monitor_unsupported`(DDC 없음), `502 monitor_failed`(모니터가 거절), `504 timeout`. 예시는 `testdata/st-v1/command.monitor_*.json`.
  - 이 명령들만 value가 문자열일 수 있어, `/st/v1/command`는 본문을 먼저 읽고 `monitor_*`이면 `MonitorCommandRequest`(value = raw JSON)로 따로 디코드한다. 다른 명령의 `CommandRequest.Value *int`는 그대로다.
- **앱**: 명령 탭 "모니터" 카드(밝기 슬라이더 · 입력 선택 · 켜기/끄기, 끄기는 확인), `/api/monitor` GET/POST. 설정 탭 미디어·알림 절에 옵트인 스위치.
- **텔레그램**: `/brightness [0-100]`, `/input [이름]`(인자 없으면 지금 읽은 목록), `/monitor on|off`, `/status`에 `모니터: 밝기 40% · HDMI1`.

> **주의 — 끈 뒤 다시 켜기**: 많은 모니터가 DPM off 상태에서는 DDC/CI 명령을 받지 않는다. 그러면 `monitor_power on`은 `502 monitor_failed`("some monitors stop listening to DDC/CI once off")로 실패하고 모니터 전원 버튼으로만 켤 수 있다. 사용자 문구(설정 힌트, 끄기 확인, 텔레그램 답)에 미리 알린다. 이 PC의 화면 끄기(`turnscreenoff`, SC_MONITORPOWER)와는 다른 기능이다.
